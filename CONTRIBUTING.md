# Contributing

Solo-maintained. PRs and issues are welcome, response time varies.

1. `bun run lint`, `bun run test` and `bun run build` should pass.
2. Test against a real Supabase project if you touch data fetching.
3. Keep PRs to one change.

Bugs: open an issue with the template. Anything touching auth, RLS or secrets: email the maintainer instead of opening a public issue.
